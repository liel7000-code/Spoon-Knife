# Project skills

`threejs-*`: three.js skills by CloudAI-X (https://github.com/CloudAI-X/threejs-skills), MIT licence
(see THREEJS-SKILLS-LICENSE). They are written for three.js r186; this project uses three.js 0.169
(drift-game/package.json), so APIs added after r169 (HDRLoader, Timer, RenderPipeline, ...) are not
available here unless the project upgrades three.js.
